Contenido ya estudiado en el curso Contenido nuevo (y su función)
Estructura básica HTML (head, body).

Selectores de clase (.container) y etiqueta (body) en CSS. 		@media (max-width: ...): Son Media Queries. Su función es aplicar bloques de CSS solo cuando la pantalla cumple ciertas condiciones (por ejemplo, cuando la pantalla del usuario mide 760px de ancho o menos). Es la base para hacer que la página sea responsiva y se adapte a celulares.

@keyframes scrollDown: Permite crear animaciones personalizadas cuadro por cuadro. Define cómo debe verse un elemento al 0%, 70% y 100% de la animación.
Propiedades básicas de color y texto (color, font-size, font-weight).

Medidas tradicionales como px o %. 		:root y var(--nombre): Son variables nativas de CSS. Sirven para guardar un valor (como el color azul en --navy) en la raíz del documento y reutilizarlo en todo el archivo. Si se quiere cambiar el color, solo se cambia una vez arriba.

clamp(...): Es una función matemática de CSS. Su función es calcular automáticamente el tamaño de la letra para que escale con el ancho de la pantalla y se mantenga entre un mínimo y un máximo.
Etiquetas para texto, enlaces y listas (h1, p, a, ul, li).

Agrupación de elementos con contenedores clásicos (div). 		display: grid y grid-template-columns: Es el sistema CSS Grid. Su función es dividir la pantalla en una cuadrícula perfecta (filas y columnas) para colocar tarjetas o elementos sin tener que calcular márgenes manualmente.

Etiquetas svg y path: Son Gráficos Vectoriales Escalables incrustados directamente en el HTML. Sirven para poner iconos que no pierden calidad al hacer zoom y que pueden cambiar de color mediante CSS.

backdrop-filter: blur(8px): Aplica un efecto visual de desenfoque al fondo de un elemento, creando un efecto de vidrio esmerilado para que deje ver el fondo borroso.
